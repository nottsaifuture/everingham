# Everingham — Church Farm, Ripley

Interactive 3D house-plan demonstration for the Everingham at Church Farm, Ripley.

[Open the viewer](https://nottsaifuture.github.io/everingham/)

Use the floor and dollhouse controls to explore the layout. Select Walkthrough to approach the entrance, open doors, and walk through the house. Touch controls are available for phones and tablets.

Independent demonstration · not affiliated with or endorsed by Langridge Homes

Dimensions, finishes and furnishings are illustrative. This repository contains built website files only; editable source is retained locally.
